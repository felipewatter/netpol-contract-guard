# Changelog

This project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and Semantic Versioning.

## [0.1.0] — 2026-11-09

### Added
- Offline NetworkPolicy connectivity contract engine with bidirectional isolation and additive policy semantics.
- Kubernetes-native Pod and namespace label selectors, matchExpressions, CIDR/except and TCP/UDP/SCTP ports.
- Named destination ports, numeric endPort and explicit platform-ambiguity rejection.
- Version-controlled allow/deny contracts, security regression comparison, text/JSON/SARIF outputs and severity-based blocking.
- Bounded strict JSON ingestion, deterministic test fixtures and release artifact generation.
- Comprehensive tests, PT-BR/EN documentation and nine CI platform combinations.
